Implement the work described by the user in the spec or tickets.

Load `tdd` via OpenCode's `skill` tool when test-first work is appropriate, at pre-agreed seams.

Run typechecking regularly, single test files regularly, and the full test suite once at the end.

Once done, load `code-review` via the `skill` tool to review the work, including uncommitted changes when applicable.

Report the completed work and checks. Commit only if the user explicitly requests it.
